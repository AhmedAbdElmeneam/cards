## لما تبيع كارت جديد
1. افتح لوحة التحكم، وادخل بحساب Google.
2. اكتب اسم العميل، والرابط بالإنجليزي (مثلاً `mona`)، ودوس **اعمل عميل جديد**.
3. هيطلعلك كود جديد عشوائي ولينكين:
   - **لينك الكارت**: اكتبه على الكارت من أبلكيشن NFC Tools (Write ← Add a record ← URL).
   - **لينك التعديل**: ابعته للعميل بس. أو دوس **انسخ رسالة جاهزة** وابعتها على الواتساب.
4. العميل يفتح لينك التعديل، ويحط صورته ولينكاته ويدوس **حفظ**، والكارت بيفتح على صفحته على طول.

## لو لينك تعديل اتسرّب
- **كود جديد**: من لوحة التحكم جنب العميل. القديم بيبطّل في ساعتها، وبياناته بتفضل زي ما هي.
- **إلغاء الكود**: بيقفل التعديل خالص، وصفحة الكارت بتفضل شغالة.

## Firebase (مشروع `meneam-cards`، خطة Spark المجانية)
- **Firestore Database** فيها 3 مجموعات:
  - `profiles`: بيانات كل كارت، واسم الـ document هو الرابط (`mona`).
  - `keys`: أكواد التعديل، واسم الـ document هو الكود، وجواه `slug` يعني الكود ده بيفتح أنهي كارت.
  - `sessions`: بتتعمل لوحدها لما حد يفتح لينك تعديل. متلمسهاش.
- **Authentication**: Anonymous للعملاء، و Google ليك إنت.
